# 📊 E-Commerce Analysis — Power BI Dashboard

## 🔍 Overview

This project consists of interactive Power BI dashboards (`dashboard/e-commerce aanaylsis.pbix`) that break down business performance into three main views:

1. **Sales Analysis Overview**
2. **Products Analysis Overview**
3. **Customers Analysis Overview**

All reports include slicers for **Month**, **Payment Method**, and **Region**, enabling dynamic, drill-down exploration of the data.

## 🚀 How to Use

1. Clone or download this repository.
2. Open `dashboard/e-commerce aanaylsis.pbix` in Power BI Desktop.
3. The raw dataset used to build the model is available in `data set/E-CommerceSales_Tableau_Dataset (1).xlsx`.
4. Use the slicers (Month, Payment Method, Region) to explore the data interactively.
